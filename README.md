# Filton & District Social Club

Website for Filton & District Social Club — a members' club in Filton, Bristol. Live sport, Saturday night entertainment, bingo, skittle teams, room hire and a dog-friendly bar.

Built with React, TypeScript, Vite and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deployed on Vercel.
